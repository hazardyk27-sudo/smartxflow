# i18n Faz Geçmişi (Arşiv)

Bu dosya, `replit.md`'de yer alan i18n (7 dil: TR/EN/DE/FR/NL/IT/ES) çalışmasının tamamlanmış faz geçmişini, hangi dosyalara kaç yamama yapıldığını ve kullanılan patcher script'lerini kayıt altında tutar. Güncel/aktif i18n durumu için `replit.md` içindeki kısa özet yeterlidir; buradaki detaylar artık değişmeyecek geçmiş iş kayıtlarıdır.

## Faz 5 — i18n Master Catalogue
Tek hakikat kaynağı `static/i18n/_master.csv` — kolonlar: `key, file_refs, tr, en, de, fr, nl, it, es` (7 dil = TR + EN/DE/FR/NL/IT/ES). `file_refs` = noktalı virgülle ayrılmış `path:line` listesi. Build pipeline: `python3 scripts/i18n_master.py {sync|build|stats}` — `sync` JSON→CSV (file_refs korunur), `build` CSV→7 JSON (boş çeviri TR fallback), `stats` kapsam raporu. Auditor: `python3 scripts/i18n_extract.py [--csv]` — sarılmamış TR string'leri raporlar. **Detection iki katmanlı:** (1) TR diacritic karakterler (ığşöüçĞŞÖÜÇİ); (2) ASCII-TR kelime allowlist (toplam, kazanan, kaybeden, kaybetti, oran, para, tumu, hacim, lider, takip, ediyor, kisi, mac, lig, snapshot, ev sahibi, deplasman, beraberlik, gelen, sonuc, guven, iade, iptal, ortalama, esik, aktif, sinyal, vb.) — diakritiksiz TR (ör. "Toplam", "Kaybetti", "Tumu", "Buyuk Para") da yakalar. Brand allowlist (SmartXFlow, MIM, Sharp, Big Money, Moneyway, MW, Underdog Pressure, Confirmed Money, Early Money Lock, Fake Sharp, Dropping Odds, Volume Shock, Public Move, HUGE MONEY) — strip-then-check mantığı: sadece brand içeren metinler raporlanmaz. False-positive filter: CSS sınıfları (`^[a-z][a-z0-9_-]*$`), URL'ler (`^https?://`, `/api/`, `/static/`), broken \u-escape leftover'ları, console.log/[Tag] developer-debug çağrıları. Auto-wrapper: `python3 scripts/i18n_wrap.py [--apply]` üç farklı strateji uygular: (1) **plain JS literal** → `_t('key','TR')` (önceki char identifier ise leading space — `return_t(...)` bug yok); (2) **HTML fragment string literal** (`'<span>X</span>kişi takip ediyor'`) → token-bazlı segment splitting + concat: `'<span>X</span>'+_t('k','kişi takip ediyor')`; (3) **template literal interpolation** (`` `${count} yeni alarm bulundu!` ``) → text segment'leri `${_t('k','TR')}` enjekte ederek; gerçek `${EXPR}` ifadeleri korunur (iter_js_strings interps listesi). HTML tag'lerine `data-i18n="key"` veya `data-i18n-attr="attr:key"` enjekte. Master CSV'ye yeni key + file_refs otomatik kaydedilir. Hedef dosyalar: app.js + ui.js (JS), 12 template (index/landing/nedir/rehber*4/pricing/legal/analysis/match_detail/status). `static/js/inline.js` kapsamdan çıkarıldı (densely-packed dinamik HTML template fragment bundle, yapısal restructure ister). Mevcut: **949 master key**, TR %100, diğer 6 dil %78.4 (yeni 205 key TR fallback ile çalışır; çeviri için master CSV'yi düzenleyip `build` çalıştır). **Audit: 0 unwrapped TR** (genişletilmiş ASCII + HTML-fragment kapsam).
